How to install (Android)

  1. Tap Download above.
  2. Open the file when it finishes (from the notification or the Downloads folder).
  3. The first time, Android asks to allow installs from your browser: tap Settings, turn on Allow from this source, then go back.
  4. Tap Install.

Updates install over the old version: no need to uninstall, your settings stay.

How to install (iPhone)

  1. Open the link in Safari (not Chrome or inside Messenger).
  2. Tap the Share button.
  3. Tap Add to Home Screen, then Add.
  4. Open SVL ASX from the home screen, go to News, and switch Alerts on (needs iOS 16.4 or newer).

Android: download above. iPhone: use the iPhone button. Pretend-money trading information, not financial advice.
