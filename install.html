Install the Share/Crypto Trades phone app

The phone app shows the same picks and prices as this website, and can buzz your phone when something on your watch list moves. Version 1.9.0, for Android phones. There is no iPhone version yet: on an iPhone, open this website in Safari and choose Share → Add to Home Screen.

Before you start. The app file is not on the Play Store yet. Ask Ryan for the file named ShareCryptoTrades_v1.9.0.apk; he sends it directly. Only install a copy that came from him.

1. Get the file onto the phone

  1. Open the message, email or shared folder Ryan sent it in, on the phone.
  2. Tap ShareCryptoTrades_v1.9.0.apk to download it.

2. Allow the install

  1. Android asks whether to allow installs from this source (for example Chrome or Files). Tap Settings.
  2. Turn on Allow from this source, then go back.
  3. If Play Protect warns that the app is unknown, tap More details → Install anyway. It is unknown only because it is not on the Play Store.

3. Install or update

  1. Tap Install. If an older ASX Desk / Share-Crypto app is already on the phone, this installs over it and keeps your settings.
  2. Open the app. It shows the most recent numbers it has saved straight away.

4. Connect it for live numbers

  1. The app shows an 8-character code, like 1A2B-3C4D.
  2. Send that code to Ryan. He types it on his PC once; that links this phone and no other.
  3. Within a minute or two the app starts getting live numbers. The code is not a password: it only lets Ryan check it is your phone.

If something goes wrong

  • "App not installed": an old copy signed differently is on the phone. Uninstall it, then install again.
  • No live numbers after pairing: Ryan's PC may be off. The saved numbers still show.
  • Anything else: use the feedback page.
